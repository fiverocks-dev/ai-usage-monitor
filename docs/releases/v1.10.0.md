# AI Usage v1.10.0 — Release Notes

Release date: 2026-11-01 (planned)

## Added
- Separate Google Antigravity Gemini (AG-G) and Claude/GPT (AG-C) quota displays, using `agy /usage` structured account-level quota data when available.
- Optional Gemini 4 Argon weekly quota column (AG-A), off by default and enabled from **Monitored services > Argon (7d)**.
- Persistent ordering of `5h / 7d` or `7d / 5h` usage rows.

## Fixed
- Respect a provider's disabled five-hour quota window when the weekly Claude/GPT quota has been exhausted.
- Improve Windows taskbar recovery after Explorer restarts and session changes, including multi-monitor placement behavior.

## Reliability and fallback
- If `agy` is absent or its structured quota response is unusable, the monitor falls back to the existing authenticated Antigravity API.
- That fallback may not contain Gemini weekly or independent Argon data; missing values are not inferred from unrelated quota groups.
- Application settings are preserved during upgrades; `show_argon` defaults to false for older settings.

## Verification and provenance
- The functionality was merged as [PR #11](https://github.com/fiverocks-dev/ai-usage-monitor/pull/11) and [PR #10](https://github.com/fiverocks-dev/ai-usage-monitor/pull/10).
- [CI #148](https://github.com/fiverocks-dev/ai-usage-monitor/actions/runs/41075222660) passed before the version bump. Release candidate CI and publishing workflow results must be checked separately for this release's exact commit.
- Argon opt-in was verified by a Windows interactive user test.
- Longer-term auto-refresh and taskbar positioning remain operational monitoring concerns; any new regressions should be tracked as new issues.
